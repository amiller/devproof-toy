Devproof — Encrypted KV Store

A key-value store where values are encrypted inside a TEE (Trusted Execution Environment) and stored in Postgres as ciphertext. The database is auditable but private — only the TEE can decrypt.

API

Base URL: https://devproof-toy.vercel.app

POST /api/session

Create an anonymous session. Returns a cookie for subsequent requests.

curl -c cookies.txt -X POST https://devproof-toy.vercel.app/api/session
# → {"userId":"user-a1b2c3d4e5f6a7b8"}

POST /api/records

Store an encrypted record. Value is encrypted inside the TEE before writing to Postgres.

curl -b cookies.txt -X POST https://devproof-toy.vercel.app/api/records \
  -H "Content-Type: application/json" \
  -d '{"key":"my-secret","value":"hello world"}'
# → {"ok":true,"key":"my-secret"}

GET /api/records?key=...

Read a record. The TEE decrypts the value before returning it.

curl -b cookies.txt https://devproof-toy.vercel.app/api/records?key=my-secret
# → {"key":"my-secret","value":"hello world"}

GET /api/records

List all records for your session. Keys are visible, values are ciphertext.

curl -b cookies.txt https://devproof-toy.vercel.app/api/records
# → {"records":[{"key":"my-secret","ciphertext":"{\"iv\":\"...\",\"data\":\"...\",\"tag\":\"...\"}"}]}

GET /api/verify

Verify the TEE is running attested code. Checks health, compose hash (links to source), and stats.

curl https://devproof-toy.vercel.app/api/verify
# → {"verified":true,"checks":[...]}
