  Encrypted KV store: The TEE connects directly to a Postgres database but encrypts all
  values with AES-256-GCM before writing. The DB holds only ciphertext — auditable but private.
  The encryption key never leaves the TEE. Vercel handles sessions and proxies requests.
  


  TLS oracle: The TEE fetches HTTPS URLs, captures TLS fingerprints,
  and signs responses with a TEE-derived key. The TDX quote attests the enclave code.
  Client-side verification using @noble/curves proves the response is authentic.
  The compose hash links the running enclave to its
  open source code.
  


  Exit report: A signed snapshot of TEE activity — verifiable offline, even after shutdown.
